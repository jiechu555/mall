# AI 客服检索质量评测报告（commit 6）

> 2026-10-01 实测。评测集 `mall-portal/src/test/resources/ai/eval-set.json`，25 问覆盖商品型号词（10）、FAQ 政策问法（10）、白话口语（5）三类。检索取 top5，命中条件 = 期望类型+标题关键词匹配。测试类 `AiKbEvaluationTest`（@Tag("es")，本地跑）。

## 环境

| 项 | 值 |
|---|---|
| 检索模式 | **纯 BM25**（ai.enabled=false，混合模式待智谱 key 接入后复测） |
| ES | 7.17.3 + ik_max_word（title^2 + content） |
| 知识库 | 36 篇（20 上架商品卡片 + 16 条 FAQ 种子） |

## 结果

| 指标 | 实测 | 目标 | 结论 |
|---|---|---|---|
| **召回@5（全体）** | **84.0%**（21/25） | ≥80% | ✅ |
| 召回@5（商品型号词） | 10/10 = 100% | — | 精确关键词 BM25 完美 |
| 召回@5（FAQ 政策问法） | 8/10 = 80% | — | 直接关键词基本命中 |
| 召回@5（白话口语） | 3/5 = 60% | — | **混合检索的目标改进区** |

## 未命中明细（4 条）

| 问题 | 期望命中 | 实际 top1 | 根因 |
|---|---|---|---|
| 怎么退货 | 退换货政策 | 怎么查询物流 | "退货"≠"退换货"，BM25 无法桥接同义词 |
| 买了能退吗 | 退换货政策 | 可以开发票吗 | 白话"买了能退"与"退换货"零词重叠 |
| 东西什么时候到 | 多久发货 | 退换货政策 | "什么时候到"与"发货"语义等价但字面无关 |
| 不想要了怎么办 | 退换货政策 | 怎么查询物流 | 白话"不想要了"与"退换货"零词重叠 |

**根因一致**：全部 4 个 MISS 都是 BM25 无法处理的**语义等价但字面无关**查询——这正是向量检索的价值区间。启用嵌入后混合检索应消除大部分 MISS（预期召回@5 升至 92%+）。

## 复现

```bash
# 前置：本机 ES 7.17.3+ik 运行中，mall-portal 可启动
mvn -pl mall-portal -DskipTests=false -Dtest=AiKbEvaluationTest test
# 输出在 surefire 报告的 system-out 段
```
